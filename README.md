# Marlons Claude-Skills

Fertige Skills für Claude Code. Einmal die Bibliothek hinzufügen, dann jeden Skill
mit einem Befehl installieren. Neue Skills und Updates kommen von allein.

## Einmal hinzufügen

In Claude Code (Desktop-App, Code-Tab) eingeben:

```
/plugin marketplace add Marl0n98/claude-skills
```

## Skill installieren

Entweder `/plugin` eingeben und aus der Liste wählen, oder direkt:

| Skill | Was er kann | Befehl |
|---|---|---|
| Humanize dein KI-Text | Anleitung: Text klingt nicht mehr nach KI (DE + EN) | `/plugin install humanizer@marlon-skills` |
| Claude Rat | 5 KI-Berater statt einer Antwort | `/plugin install llm-council@marlon-skills` |
| KI-Harness-Architekt | Das kleinstmögliche KI-Setup für deine echte Arbeit | `/plugin install ki-harness-architekt@marlon-skills` |
| Video-Prompt-Builder | Shot-für-Shot-Prompts für Seedance und Higgsfield | `/plugin install video-prompt-builder@marlon-skills` |
| Claude als Videoeditor | Anleitung: Claude schneidet dein Video per Beschreibung (Remotion) | `/plugin install ugc-editor-letzter-retake@marlon-skills` |
| Digitaler Fußabdruck | Deine Daten aus Datenhändlern und Suchseiten löschen | `/plugin install digitaler-fussabdruck@marlon-skills` |
| Digitaler Fußabdruck Pro | Deine Daten im Netz finden und löschen lassen, in jedem Land, ohne Technikwissen | `/plugin install digitaler-fussabdruck-pro@marlon-skills` |
| Bewerbungs-Coach | Lebenslauf, Anschreiben, Interview, Gehalt, ohne dass Claude etwas erfindet | `/plugin install bewerbungs-coach@marlon-skills` |
| Loop-Engineer | Aufgaben, die von allein laufen, statt Prompts, die dich festhalten | `/plugin install loop-engineer@marlon-skills` |
| Vertrags-Check | Verträge, AGB und NDAs mit Ampel prüfen, bevor du unterschreibst | `/plugin install vertrags-check@marlon-skills` |
| Aktien-Analyst | Jede Aktie in 5 Schritten in unter 5 Minuten | `/plugin install aktien-analyst@marlon-skills` |
| Script-Writing | Reel-Skripte mit offenen Loops, die keiner wegwischt | `/plugin install script-writing@marlon-skills` |
| Divergence | Ideen, die keine KI von allein hätte | `/plugin install divergence@marlon-skills` |
| Google-Ads-Auditor | Verbranntes Budget in Euro finden | `/plugin install google-ads-auditor@marlon-skills` |
| E-Mail-Auditor | Wo dein E-Mail-Marketing Umsatz liegen lässt | `/plugin install email-marketing-auditor@marlon-skills` |

Danach Claude einmal neu starten. Claude nutzt einen Skill von allein, wenn deine Aufgabe
passt. Du kannst ihn auch direkt aufrufen: `/` tippen und den Namen wählen.

## Updates

```
/plugin marketplace update marlon-skills
```
